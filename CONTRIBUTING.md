# Contribuindo para o DeskHub

Obrigado por contribuir com o DeskHub!

## Fluxo recomendado

1. Abra uma issue descrevendo a proposta.
2. Discuta arquitetura antes de implementar.
3. Envie PR com contexto e testes.

## Princípios

- Manter módulos desacoplados.
- Priorizar documentação antes de código.
- Preservar compatibilidade com arquitetura definida em `docs/TECHNICAL_MASTER_PLAN.md`.
