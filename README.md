# DeskHub

Painel inteligente open source baseado em ESP32 para centralizar informações pessoais, profissionais e de automação residencial em um único dispositivo físico.

> DeskHub não é apenas um display. É uma plataforma modular para dashboards embarcados.

## Visão

DeskHub foi concebido para evoluir como uma plataforma completa, separando firmware, backend, frontend e hardware para permitir evolução independente e integração contínua de novos widgets, dispositivos e serviços.

## Princípios

- Offline First
- Open Source
- Modular
- Extensível
- Atualização OTA
- Arquitetura desacoplada
- Hardware reproduzível
- Fácil manutenção
- Alta documentação
- Widgets independentes
